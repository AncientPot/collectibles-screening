# 暗区突围无限 · 听声鉴宝

监听游戏内的物品拾取声音，自动比对识别声音类别，并按类别筛选出对应物品清单，辅助藏品甄别。

## 环境要求

- Windows 10/11（环回采集依赖系统的 WASAPI）；
- 从源码运行需要 Python ≥ 3.14，并用 [uv](https://docs.astral.sh/uv/) 管理依赖。

## 启动

同步环境：

```powershell
uv sync
```

源码运行：

```powershell
uv run app.py
```

或直接运行打包好的 `dist\听声鉴宝\听声鉴宝.exe`（须与同目录的 `_internal`、`data` 在一起，整体文件夹分发）。

## 首次使用

系统需要先构建输出模板（基准音频在真实输出信道下的采集样本）才能开始监听：

1. 首次启动时若模板不存在，监听按钮不可用，并在右侧提示「请进入设置界面构建输出模板」；
2. 进入设置点击「构建输出模板」，系统依次播放 10 段基准音并环回采集（约 20 秒，期间保持安静、关闭其他出声程序）；
3. 构建完成后监听自动开放。更换音频设备或驱动后，可点击「重构输出模板」重新采集。

## 基本用法

1. 点击监听，拖拽货物一次后，结束监听，监听按钮右侧会显示相似度，内容区按该声音筛选出候选物品；
2. 类型、格式、声音三个条件自动取交集，可随时手动改选缩小范围；
3. 声音选择栏可手动切换类别，点播放可试听该类别的基准音频。

## 保存学习（提高识别准确率）

- 遇到误判时：重听该物品声音并监听录制，点保存学习、在弹出的窗口中选择正确的声音类别后，确认保存；
- 保存后的新模板约两秒自动生效（右侧短暂提示「学习模板已更新」），之后同类声音的识别会被修正；
- 学习音频按类别存放在 `data/save/类别/` 下，超出类别上限时自动删除最旧的；
- 学习数据按类别均衡积累效果最佳。

## 快捷键

1. 监听快捷键：默认小键盘 `+`；
2. 窗口（取消）置顶快捷键 `-`。

均可在设置中修改；游戏占用键位时请换键，游戏以管理员权限运行时需以管理员身份启动本程序。

## 设置界面

- 最长监听时长：单次录音上限（默认 5 秒，到时自动结束并比对）；
- 播放音量：基准音频播放倍率，默认 5（听不清可调大）；
- 学习数据权重（0-1）：0 为不使用学习数据，0.5 为默认微调力度，1.0 为与保底模板平权；
- 学习音频上限：按类别设置，下拉选择类别后在输入框修改数量，超出自动删除最旧；
- 监听/置顶快捷键：点录制后按新键，Esc 取消（两者不能相同）；
- 查看音频：查看各类别学习音频数量与刚录制标记，可删除指定音频；
- 构建/重构输出模板：见「首次使用」；
- 说明：各参数的详细说明。

## 数据目录

| 路径 | 内容 |
|---|---|
| `data/original_ audio/` | 10 个声音类别的原始基准音频 |
| `data/audio_cache/templates/` | 输出模板（基准在同信道下的采集样本） |
| `data/audio_cache/` | 特征缓存（删除后自动重建） |
| `data/save/类别/` | 学习音频（按类别子目录存储） |
| `data/collected_audio/` | 最近一次监听的录音 |
| `data/json_map/` | 物品-类别-品质映射数据 |
| `data/config.json` | 设置持久化 |

## 项目结构

```
app.py                 入口
src/
  main_window.py       主窗口组装
  core/                业务逻辑：录音、比对、筛选、保存学习、设置
  widgets/             界面组件：顶栏、内容区、设置对话框等
  utils/               数据目录定位与布局工具
data/                  运行数据与映射（见上表）
doc/                   项目文档
```

代码规范见 `AGENTS.md`。

## 已知问题

- 三个下拉框的弹出列表做了延迟一帧显示与同步重绘加固，用于规避 Windows 上偶发的首帧透明列表；代价是「按下箭头后拖拽直接选 item」的手势不可用（需先点开再点选）。

## 打包

```powershell
uv run pyinstaller --noconsole --name 听声鉴宝 --hidden-import librosa.feature --hidden-import librosa.core.audio --clean --noconfirm app.py
```

1. 重新打包前先删除 `dist\听声鉴宝\` 下的旧产物（目录被占用删不掉时，先关闭停在该目录的程序）；
2. 构建完成后将 `data` 目录整个拷入 `dist\听声鉴宝\` 即可分发；
3. `build\` 与 `听声鉴宝.spec` 为构建中间产物，可删除。
