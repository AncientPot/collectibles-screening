# 暗区突围无限 · 听声鉴宝

监听游戏内的物品拾取声音，自动比对识别声音类别，并按类别筛选出对应物品清单，辅助藏品甄别。

## 启动

同步环境：
```powershell
uv sync
```
源码运行：
```powershell
uv run app.py
```

## 基本用法

1. 点击监听，拖拽货物一次后，结束监听，监听按钮右侧会显示相似度，内容区按该声音筛选出候选物品；
2. 类型、格式、声音三个条件自动取交集，可随时手动改选缩小范围；
3. 声音选择栏可手动切换类别，点播放可试听该类别的基准音频。

## 保存学习（提高识别准确率）

- 遇到误判时：重听该物品声音并监听录制，点保存学习、在弹出的窗口中选择正确的声音类别后，确认保存。
- 保存后的新模板自动生效，之后同类声音的识别会被修正。
- 学习数据按类别均衡积累效果最佳。

## 快捷键

1. 监听快捷键：默认小键盘`+`；
2. 窗口（取消）置顶快捷键`-`；

## 设置界面

- 最长监听时长：单次录音上限（默认 5 秒，到时自动结束并比对）；
- 播放音量：基准音频播放倍率，默认 5（听不清可调大）；
- 监听/置顶快捷键：点录制后按新键，Esc 取消；
- 重建保底模板：更换音频设备/驱动后使用。点击后依次播放 10 个基准音并环回采集（约 20 秒，期间保持安静），完成后立即生效。

设置会持久化到 `data/config.json`。

## 数据目录

| 目录 | 内容 |
|---|---|
| `data/original_ audio/` | 10 个声音类别的原始基准音频 |
| `data/audio_cache/templates/` | 保底模板（基准在同信道下的采集样本） |
| `data/audio_cache/` | 特征缓存 |
| `data/save/` | 保存学习的采集音频 |
| `data/collected_audio/` | 最近一次监听的录音 |
| `data/json_map/` | 物品-类别-品质映射数据 |
