# 听声鉴宝

暗区突围无限「行商」活动听声鉴宝自用工具:听到音效后按类别、格式、声音筛选候选物品,并试听参考音效辅助辨认。

> 最初打算用算法自动识别声音,试下来效果一般——还不如人耳分辨得快,于是这一版干脆做成了以分类筛选为主的音频播放器。声音相似度对比之类的,以后有心情再考虑(活动都快结束了,大概率不会再折腾了)。

## 使用

**程序启动**:双击 `听声鉴宝.exe`,需确保 `data` 目录与 exe 位于同一目录下。

**源码启动**:

```bash
uv sync           # 同步虚拟环境依赖
python main.py    # 不在虚拟环境时自动转入项目 .venv 启动
```

- 默认热键:`←` 置顶/置底切换,`→` 播放选中声音,`↑`/`↓` 切换声音选项(固定不可改);
- 筛选:类别、格式、声音三个下拉任意组合,取交集;
- 设置(工具栏"设置"按钮):调音量、改热键、添加/删除物品,音量与热键会记住;
- data 内文件的改动会自动热加载,无需重启;JSON 改坏了不会崩,改对保存后自动生效。

## data 目录说明

| 路径 | 内容 |
| --- | --- |
| `data/json_map/collection_map.json` | 物品主表:物品名 → 格式/类别/品质/声音 |
| `data/json_map/category_map.json` | 类别 → 该类别的物品名列表 |
| `data/json_map/footprint_map.json` | 格式 → 该格式的物品名列表 |
| `data/json_map/audio_map.json` | 声音 → 同声物品名列表 |
| `data/original_ audio/声音名/声音名_0.wav` | 参考音效:一个声音一个同名目录,多个录音依次编号 _0、_1 |
| `data/config.json` | 本机偏好(音量、热键),首次在设置里改动后生成 |

## 添加新声音

1. 在 `audio_map.json` 增加一个键:`"新声音名": []`(成员列表可以为空);
2. 建目录 `data/original_ audio/新声音名/`,放入 `新声音名_0.wav`;
3. 有音频文件且组内有"红"品质物品 → 有红组;有音频无红 → 无红组;暂无 wav → "暂无声音"分组,放入后自动归位。

## 手动改 json 增删物品

**添加**:在 `collection_map.json` 末尾追加物品条目(json 中越靠下越新),并把物品名同时加进
`category_map`、`footprint_map`、`audio_map` 对应的三个列表——**四处必须一致**,
启动时校验,不一致会报错并指出具体条目。

**删除**:反向操作,四处同步移除该物品名。

也可以直接在设置界面用"添加/删除"按钮,程序会自动改这四个文件。
